# Predicting Fraudulent Credit Card Transactions

In this project, I present a practical approach to developing two classifier models in Python (RandomForestClassifier and XGBoost)
capable of detecting fraud in a large dataset of financial transactions, combining statistical analysis, machine learning techniques, and best practices in data science.

The data used can be found here: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

## Topics covered in the project

1. Libraries
2. Exploratory Data Analysis (EDA)
3. Machine learning models
   
   3.1 RandomForestClassifier
   
   3.2 XGBoost

4. Conclusion
